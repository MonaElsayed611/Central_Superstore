# Advanced SQL Data Warehouse & Business Analytics

## Project Overview

This project focuses on designing a relational data warehouse and performing business analytics using the **Central Superstore** dataset.

The objective is to transform raw retail data into a structured analytical database that supports business reporting, KPI monitoring, and data-driven decision-making.

The project applies data warehouse design principles, advanced SQL techniques, and analytical queries to explore sales performance, profitability, customer behavior, and sales trends.

## Business Objectives

- Design a relational database using a **Star Schema** architecture.
- Organize retail data into fact and dimension tables.
- Establish primary and foreign key relationships.
- Analyze sales performance and profitability.
- Explore customer purchasing behavior.
- Identify sales trends and key business performance indicators (KPIs).
- Improve query readability and performance.

## Dataset

**Dataset Name:** `Central_Superstore.xlsx`

The dataset contains retail-related information used to support sales, customer, product, and profitability analysis.

The data is transformed into a relational structure suitable for analytical queries and business reporting.

## Tools & Technologies

- SQL Server  — Relational database management.
- SQL — Data modeling, querying, and business analytics.
- Data Warehouse Concepts** — Fact tables, dimension tables, and Star Schema design.

*The specific database platform and supported SQL syntax depend on the implementation.*

## Database Design

The project follows a Star Schema approach, separating measurable business transactions from descriptive information.

### Fact Table
Stores transactional measures and foreign keys linking transactions to the relevant dimensions.

### Dimension Tables
Organize descriptive attributes used to analyze business performance from different perspectives, such as customers, products, and dates.

The final schema includes at least five relational tables, connected through primary and foreign key relationships.

## SQL Analysis & Implementation

The project covers the following technical components:

### 1. Database Design
- Data normalization and relational table design.
- Fact and dimension table creation.
- Primary and foreign key constraints.
- Star Schema modeling.

### 2. Advanced SQL Queries
- Multi-table JOIN operations.
- Subqueries for conditional and comparative analysis.
- Common Table Expressions (CTEs) for organizing complex queries.
- CASE statements for classification and conditional calculations.
- Aggregations and grouping for KPI analysis.

### 3. Views & Stored Procedures
- SQL views for reusable analytical datasets and reporting.
- Stored procedures for KPI calculations and repeatable analytical operations.

### 4. Business Analytics
- **Sales Analysis:** Revenue and sales performance across products and time periods.
- **Profitability Analysis:** Profit performance and comparisons across relevant business categories.
- **Customer Analytics:** Customer purchasing patterns and contribution to business performance.
- **Trend Analysis:** Changes in sales and profitability over time.
- **KPI Monitoring:** Calculation of relevant business metrics to support decision-making.

### 5. Query Optimization
Reviewing query structure and applying appropriate optimization techniques to improve readability and execution efficiency.
